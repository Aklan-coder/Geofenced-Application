# Geofenced Application

A GPS-based Android mobile application built with Kotlin and Android Studio.

## Project Description

This application demonstrates the use of the GPS sensor in Android devices by implementing a geofencing system.

The app allows users to:

- Start GPS tracking
- Set the current location as the geofence center
- Detect whether the user is inside or outside the geofence boundary
- Display distance from the geofence center
- Visualize movement using a radar-style interface

## Features

- GPS location tracking
- Geofence detection
- Inside/Outside zone status
- Dynamic distance calculation
- Emulator GPS testing support
- Splash screen
- Modern UI design

## Technologies Used

- Kotlin
- Android Studio
- Android GPS/Location APIs
- XML Layouts

## How to Run

1. Clone the repository
2. Open the project in Android Studio
3. Run the app on an emulator or Android device
4. Grant location permission
5. Press Start to begin tracking
6. Press Set to create the geofence center
